# BackupHub v0.3.0 — восстановление сервера и истории

- `backuphub recovery export` сохраняет согласованную копию SQLite и необходимые ключи в приватный каталог на отдельном носителе.
- `backuphub recovery restore` проверяет комплект и публикует новое состояние целиком. Восстановленные задания приостановлены, прошлые сессии закрыты.
- `backuphub recovery reconcile` добавляет в историю снимки из сохранившихся репозиториев, в том числе снимки, опубликованные после экспорта комплекта. Повтор команды сохраняет историю без дублей.
- Восстановление в новый каталог сохраняет пользовательский файл с именем служебного README. При совпадении имени файла с именем манифеста ZIP BackupHub выбирает свободное имя и сохраняет его в комментарии архива.

Процедура восстановления и требования к хранению комплекта описаны в [инструкции](../recovery.md). Сохраняйте Restic-репозитории и комплект отдельно. Независимая неизменяемая репликация, безопасная автоматическая ротация и автоматические тестовые восстановления приложений остаются в дорожной карте.

## Установка

Скачайте Debian-пакет и файл контрольной суммы из релиза.

```sh
sha256sum -c backuphub_0.3.0_amd64.deb.sha256
sudo apt install ./backuphub_0.3.0_amd64.deb
```
