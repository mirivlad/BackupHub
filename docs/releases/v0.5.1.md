# BackupHub v0.5.1

- После копирования BackupHub перечитывает данные и метаданные нового снимка перед добавлением в историю. Полная проверка всего репозитория остаётся отдельной операцией Restic.
- При конфликте блокировки BackupHub использует штатный `restic unlock` для просроченных блокировок и повторяет операцию один раз. При остановке BackupHub даёт Restic завершить работу и освободить блокировку. После перезапуска прерванное задание снова доступно для выполнения.
- **«Журнал службы»** показывает администратору последние записи systemd для `backuphub.service` и автоматически обновляется. При сбое проверки виден вывод Restic.
- Действие **«Редактировать»** рядом с заданием в выбранной ячейке расписания открывает форму этого задания.

Релиз содержит Debian-пакет amd64 и файл SHA256.
