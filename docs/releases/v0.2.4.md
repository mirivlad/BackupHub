# BackupHub v0.2.4 — удобный просмотр и скачивание резервных копий

Раздел «История копий» теперь содержит полноценный двухпанельный файловый менеджер вместо плоской таблицы путей.

- Слева — раскрываемое дерево каталогов, подгружаемое по мере необходимости. Справа — содержимое выбранной папки.
- Хлебные крошки и возврат на уровень вверх, выделение файлов и целых папок, сохранение выделения при навигации.
- Постраничный просмотр по 120 записей с загрузкой только содержимого текущей папки, без искусственного обрезания первых 2000 файлов.
- Поиск файлов и папок по всему снимку: сервер выполняет рекурсивный поиск, но возвращает только одну страницу результатов.
- Скачивание одного файла, папки ZIP, нескольких выбранных позиций ZIP и всего снимка ZIP. Восстановление выделенного в новый каталог сервера.
- Прямое скачивание одного файла больше не требует построения списка всех файлов снимка. Кириллические и другие Unicode-имена файлов корректно кодируются в HTTP-заголовке скачивания.
- Учётные записи, ключи и старые снимки остаются совместимыми.

## Установка

Скачайте .deb и SHA256 из https://github.com/mirivlad/BackupHub/releases/tag/v0.2.4

```bash
sha256sum -c backuphub_0.2.4_amd64.deb.sha256
sudo apt install ./backuphub_0.2.4_amd64.deb
```

Каталог /var/lib/backuphub при обновлении не удаляйте.

Как и прежде, BackupHub следует использовать вместе с независимой проверенной копией критически важных данных.
