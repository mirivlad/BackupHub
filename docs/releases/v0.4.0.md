# BackupHub v0.4.0 — SMB1, PuTTY PPK и копирование баз 1С

- **SMB1.** Отдельный тип источника для устройств, которым нужен SMB1. Использует Samba `smbclient` с NTLMv2 и обязательным подписыванием SMB. Клиент запускается без дополнительных полномочий демона.
- **PuTTY PPK.** Приватные ключи v2 и v3, в том числе с парольной фразой, можно загрузить в форме SSH/SFTP. BackupHub импортирует их через `puttygen` и сохраняет в зашифрованном хранилище.
- **Postgres Pro для 1С.** `pg_dump` сохраняет схему и остальную базу, двоичный `COPY` сохраняет данные `public.config`. Оба потока читают одну точку согласованности. Комплект содержит контрольные суммы и порядок восстановления в новую БД. [Инструкция по восстановлению](../postgres-1c.md)

SMB1 проверен на Samba в режиме NT1. Профиль 1С проверен копированием и восстановлением на PostgreSQL 17, включая значение `bytea` размером 520 МиБ. Перед эксплуатацией профиля 1С проверьте восстановление на своей редакции Postgres Pro и открытие тестовой информационной базы.

## Установка

Скачайте Debian-пакет и файл контрольной суммы. Обычная установка через APT также устанавливает рекомендуемые `smbclient` и `putty-tools`.

```sh
sha256sum -c backuphub_0.4.0_amd64.deb.sha256
sudo apt install ./backuphub_0.4.0_amd64.deb
```
