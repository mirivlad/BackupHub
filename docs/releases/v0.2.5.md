# BackupHub v0.2.5 — быстрый ZIP-экспорт снимков

Исправлено медленное скачивание папок с большим числом файлов через веб-интерфейс, в том числе с того же компьютера (`localhost`).

**Почему раньше было медленно:** BackupHub выполнял `restic dump` отдельно для каждого файла, каждый раз открывая репозиторий и индекс, а затем повторно сжимал уже извлечённые данные в ZIP. Для папки из сотен файлов это приводило к большой задержке и низкой скорости передачи.

**Теперь:**
- Папка, весь снимок или набор выбранных файлов, имеющих общую папку, выгружаются одним архивным потоком Restic. Из потока формируется ZIP; исключённые файлы не попадают в готовый архив.
- ZIP использует режим **Store** без дополнительного сжатия. Это экономит процессорное время и улучшает пропускную способность на локальной сети. Размер ZIP может быть больше, чем в версии 0.2.4.
- Сохраняются пути относительно исходной папки, SHA-256-манифест, отсутствие переходов по символическим ссылкам и ограничение на общий размер экспорта.
- Если выделенные файлы находятся в разных ветках снимка без общего вложенного каталога, применяется совместимый режим выборочного извлечения. Такой запрос по-прежнему может быть медленнее скачивания одной папки.
- Скачивание одиночного файла, восстановление и формат Restic не изменены.
- Добавлен интеграционный тест: 64 выбранных файла должны выгружаться **за один запуск Restic**, а ZIP должен распаковываться без ошибок.

## Установка

Скачайте `.deb` и `.sha256` из https://github.com/mirivlad/BackupHub/releases/tag/v0.2.5 в одну папку:

```bash
sha256sum -c backuphub_0.2.5_amd64.deb.sha256
sudo apt install ./backuphub_0.2.5_amd64.deb
```

Это обновление не изменяет хранилища и резервные снимки. Не удаляйте `/var/lib/backuphub` при обновлении.
