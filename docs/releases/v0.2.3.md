# BackupHub v0.2.3 — запуск без сдвига расписания

- Кнопка «Запустить сейчас» ставит независимый запрос на выполнение и не переписывает время следующего запланированного копирования.
- Повторный запрос при уже запущенном/ожидающем задании возвращает понятное сообщение и HTTP 409 вместо скрытой общей ошибки.
- В списке заданий отображаются текущая стадия выполнения и прошедшее время, повторный запуск недоступен при активном выполнении.
- Сохранение снимка и полная проверка данных Restic теперь отображаются как разные стадии — «Сохранение» и «Проверка данных».
- Список заданий и журнал обновляются автоматически каждые пять секунд.
- Если отдельный раздел не загрузился, другие остаются доступны. Ошибка указывает, в каком разделе произошёл сбой.
- Миграция SQLite v11 сохраняет задания, учётные записи, ключи и резервные копии.

Важно: `restic check --read-data` по-прежнему проверяет все данные репозитория — для больших хранилищ это длительная операция. Она теперь правильно отображается в UI, но проверка не отключена и не сокращена.

## Установка

Скачайте два файла со страницы https://github.com/mirivlad/BackupHub/releases/tag/v0.2.3 в один каталог:

```bash
sha256sum -c backuphub_0.2.3_amd64.deb.sha256
sudo apt install ./backuphub_0.2.3_amd64.deb
```

При обновлении не удаляйте `/var/lib/backuphub`: там хранятся исходные данные BackupHub и ключи.
