# BackupHub v0.5.0

- Источник **«Сетевая папка SMB»** автоматически выбирает SMB2/3. Для сервера, который согласует только SMB1, используется подписываемое подключение через `smbclient` с NTLMv2. Существующие источники SMB1 переходят на автоопределение при обновлении с сохранением параметров и учётных данных.
- Раздел **«Расписание и загрузка»** показывает ближайшие семь дней, ожидаемую длительность запусков, пересечения и свободные окна. Оценка длительности основана на медиане успешных запусков. Фактическая сетка показывает время работы исполнителя по дням недели и часам за последние 28 дней.
- **«История копий»** обновляется автоматически и показывает длительность новых копий. Из успешной записи в журнале можно открыть её снимок. Для прежних снимков без замера отображается прочерк.
- Состояния заданий и запусков получили контрастные бейджи. Журнал уточняет этап сбоя, а гибкое расписание объясняет значение каждого поля без ограничения.

В GitHub-релиз входят Debian-пакет amd64 и файл SHA256. При обновлении с прежней версии каталог мигрирует автоматически при запуске службы.
