# BackupHub 0.2.0 — новый интерфейс и независимые задания

Версия 0.2.0 перестраивает BackupHub вокруг источников, хранилищ, расписаний и заданий. Администратор отдельно указывает, **что** копировать, **куда** и **когда**.

## Новое

- Новый интерфейс: **Обзор**, **Задания**, **Источники**, **Хранилища**, **Расписания**, **История копий**, **Журнал выполнения** и **Настройки**.
- Создание источника больше **не создаёт задание автоматически**. Один источник допускает несколько независимых заданий.
- Расписания: каждые N минут/часов/дней, ежедневно в выбранное время или в определённые дни недели; для календарных запусков используется часовой пояс IANA.
- Задания объединяют источник, хранилище назначения и расписание. Есть ручной запуск, пауза и возобновление.
- Хранилище меняется у задания, а не у источника; старые снимки остаются привязанными к исходному репозиторию.
- Из рабочих экранов убраны Preview-плашки и описания нереализованных функций.
- Команда `backuphub admin-status -data-dir /var/lib/backuphub` проверяет, есть ли администратор в базе. Создание через CLI и через браузер — альтернативные способы.
- Минимальная длина нового пароля администратора — 8 Unicode-символов (Argon2id, CSRF и ограничение попыток сохранены).
- Миграция каталога SQLite v7 не требует очистки состояния.

## Установка: Debian / Ubuntu amd64

Скачайте два файла из [релиза v0.2.0](https://github.com/mirivlad/BackupHub/releases/tag/v0.2.0) в один каталог:

```bash
sha256sum -c backuphub_0.2.0_amd64.deb.sha256
sudo apt install ./backuphub_0.2.0_amd64.deb
```

Если администратор ещё не создавался:

```bash
sudo runuser -u backuphub -- backuphub setup-admin -data-dir /var/lib/backuphub
```

Откройте `https://адрес-сервера:8443/`. Установочный сертификат самоподписанный.

**При переустановке** каталог `/var/lib/backuphub` сохраняется вместе с SQLite, ключами и встроенными резервными копиями. Для совершенно чистой тестовой установки удалите его **только после проверки**, что необходимые снимки и ключи там отсутствуют. Обычное обновление этого не требует.

## Ограничения

BackupHub пока не включает безопасную автоматическую ротацию, независимые неизменяемые копии, Windows VSS/AD, PostgreSQL Pro 1C split-config и почтовые коннекторы. Проверяйте восстановление из резервных копий и сохраняйте нужные ключи независимо от сервера. Для хранилищ без пароля нужен Restic 0.17 или новее.
