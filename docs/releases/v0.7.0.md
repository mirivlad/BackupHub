## BackupHub 0.7.0

- Настраиваемые автоматические повторы после временного сбоя. По умолчанию три повтора через 30, 60 и 90 минут после завершения соответствующей попытки. Веб-интерфейс показывает причину, стадию, номер попытки и время повтора.
- У каждого задания одна логическая операция с историей в SQLite. Два исполнителя обслуживают разные репозитории. Ожидание повтора освобождает ресурсы.
- При прерывании публикации BackupHub сверяет манифест по ID операции и при возможности фиксирует существующий снимок. Принадлежащие прерванным попыткам staging-каталоги очищаются после проверки владения.
- Настраиваемые тайм-ауты подключения и прогресса. Конфликты блокировок Restic, проблемы авторизации и нарушения целостности показаны отдельными причинами.
- Миграция SQLite v15 сохраняет настройки заданий, ключи и исторические снимки. Существующие задания получают параметры повторов по умолчанию.

Сценарии испытаний, диагностика и ограничения приведены в [отчёте об отказоустойчивости](../backup-resilience.md).
