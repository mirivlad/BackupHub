# Дорожная карта до BackupHub 1.0

Это этапы **разработки** полного продукта, не урезанные «скриптовые» релизы.

## A — Фундамент
- [x] Репозиторий, лицензия, спецификация и архитектурные границы.
- [x] Go-модуль, SQLite и `instance_uuid`.
- [x] Типизированные снимки и правила составного commit, модель состояний, retention dry-run.
- [x] Минимальный read-only health API; тесты и CI.
- [ ] Миграции/бэкап каталога и самостоятельный recovery kit (миграция v1→v2 готова, аварийный комплект нет).
- [x] Vault/master key; первый администратор; сессии, базовые роли и audit (проверки авторизации и аудит действий уже введены, управление всеми ролями впереди).
- [x] Первичный Svelte UI: настройка, авторизация, источники, задания, история, скачивание ZIP и восстановление в новый каталог (полный мастер восстановления и роли/ACL ещё впереди).
- [x] Интервальный scheduler привязан к нативным источникам; persistent job-run ledger, recovery, ошибки недоступных источников (календарное расписание и политика повторов ещё нужны).
- [ ] Restic file-tree и переносимые манифесты реализованы для Preview, но ещё нужны защищённая ротация, recovery каталога, восстановление с полным сохранением метаданных и restore drills.

## B — Файловые источники
- [ ] SMB2/3, SSH/SFTP доступны как Preview для содержимого; SMB1 изолированный, ACL/xattr и расширенный fidelity — впереди.
- [ ] Исторические снимки и просмотр по именам готовы; индексирование и поиск по исчезнувшим файлам в разных датах ещё предстоит.
- [ ] Retention/hold и отдельная обслуживающая операция.
- [ ] Экспорт отдельного файла, папки и произвольной выборки в ZIP реализован в Preview; TAR/очень большие наборы/режим полного снимка требуют доработки.
- [ ] Безопасное восстановление в новый каталог готово; мастер восстановления на исходный/другой хост и ACL пока нет.

## C — Приложения
- [ ] Нативные логические бекапы PostgreSQL (обычный pg_dump -Fc в Preview; проверка совместимости pg_restore на отдельных версиях и стендовый restore нужны).
- [ ] Нативный PostgreSQL Pro 1C split-config, совместимость и стендовое восстановление.
- [ ] Windows WinRM/VSS, Thunderbird и AD System State.
- [ ] Dovecot/IMAP/ограниченный POP3 и восстановление ящиков.

## D — Доказательство надёжности
- [ ] Независимые репозитории/репликация и иммутабельность.
- [ ] Возврат данных после уничтожения BackupHub/SQLite.
- [ ] Периодические restore drills; защита, нагрузка, документация.
- [ ] Debian/systemd amd64 Preview собран с русским UI; Docker/Portainer, английский UI, hardening и production packaging ещё впереди.
- [ ] Все обязательные AT-01–AT-25 на стендах.

**Правило выпуска:** отсутствие P0-коннектора не закрывается запуском старого скрипта. 1.0 только после подтверждённых сценариев.
