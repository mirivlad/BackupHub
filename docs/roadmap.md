# Дорожная карта до BackupHub 1.0

Это этапы **разработки** полного продукта, не урезанные «скриптовые» релизы.

## A — Фундамент
- [x] Репозиторий, лицензия, спецификация и архитектурные границы.
- [x] Go-модуль, SQLite и `instance_uuid`.
- [x] Типизированные снимки и правила составного commit, модель состояний, retention dry-run.
- [x] Минимальный read-only health API; тесты и CI.
- [x] Миграции каталога, согласованная копия SQLite и [офлайн-комплект с ключами](recovery.md).
- [x] Vault/master key; первый администратор; сессии, базовые роли и audit (проверки авторизации и аудит действий уже введены, управление всеми ролями впереди).
- [x] Первичный Svelte UI: настройка, авторизация, источники, задания, история, скачивание ZIP и восстановление в новый каталог (полный мастер восстановления и роли/ACL ещё впереди).
- [x] Планировщик поддерживает интервалы, cron и ручные запуски. Журнал хранит состояние запуска и исход при недоступности источника.
- [x] Файловые снимки Restic и переносимые манифесты для импорта истории после восстановления SQLite.

## B — Файловые источники
- [x] SMB с автоматическим выбором современной версии и подписываемым SMB1 для старых серверов, SSH/SFTP и импорт PuTTY PPK доступны для резервирования содержимого.
- [ ] ACL/xattr, проверка метаданных и совместимости с дополнительными серверами.
- [ ] Исторические снимки и просмотр по именам готовы; индексирование и поиск по исчезнувшим файлам в разных датах ещё предстоит.
- [ ] Retention/hold и отдельная обслуживающая операция.
- [ ] Экспорт отдельного файла, папки и произвольной выборки в ZIP реализован; TAR/очень большие наборы/режим полного снимка требуют доработки.
- [ ] Безопасное восстановление в новый каталог готово; мастер восстановления на исходный/другой хост и ACL пока нет.

## C — Приложения
- [ ] Нативные логические бекапы PostgreSQL (обычный pg_dump -Fc в BackupHub; проверка совместимости pg_restore на отдельных версиях и стендовый restore нужны).
- [x] Копирование отдельной базы Postgres Pro для 1С с раздельной выгрузкой `public.config` и проверкой восстановления на PostgreSQL 17.
- [ ] Матрица редакций Postgres Pro для 1С и прикладное проверочное восстановление в «1С:Предприятии».
- [ ] Windows WinRM/VSS, Thunderbird и AD System State.
- [ ] Dovecot/IMAP/ограниченный POP3 и восстановление ящиков.

## D — Доказательство надёжности
- [ ] Независимые репозитории/репликация и иммутабельность.
- [x] Возврат файлов после утраты BackupHub/SQLite из офлайн-комплекта и сохранившихся репозиториев. Тест охватывает парольное и беспарольное хранилища и сбой между публикацией манифеста и записью SQLite.
- [x] Сверка дерева и потока Restic при записи снимка. Ручные и плановые проверки целостности репозиториев в двух режимах.
- [x] Ручное пробное восстановление выборки файловых источников с проверкой SHA-256 и отдельной историей.
- [ ] Стендовые прикладные восстановления PostgreSQL и других приложений.
- [ ] Периодические тестовые восстановления, измерение очереди при длительной проверке и защита при отказе хранилища.
- [ ] Пакет Debian/systemd amd64 доступен с русским UI; Docker/Portainer, английский UI, hardening и production packaging ещё впереди.
- [ ] Все обязательные AT-01–AT-25 на стендах.

**Правило выпуска:** отсутствие P0-коннектора не закрывается запуском старого скрипта. 1.0 только после подтверждённых сценариев.
