# ADR-0002 — Модульный монолит Go

**Статус:** принято, 2026-11-08.

## Решение

Один сервис Go с REST API, встроенным каталогом SQLite/WAL, браузерным UI Svelte/TypeScript. Стратегии захвата и восстановления реализуются штатными коннекторами без постоянно установленных агентов. Между коннекторами и Restic находится собственный storage contract.

Для каждого снимка нужен переносимый manifest с версией формата и restore recipe, который можно прочитать без живой SQLite. Дедупликация и криптография возлагаются на проверенный backend; никакого самодельного шифрования.

## Почему

Поддерживаемая установка на Debian/systemd и Docker/Portainer без Kubernetes, брокера задач или внешней БД. Разделение границ позволяет менять backend, не переписывая коннекторы и API. Автономные instance не зависят от других узлов.

## Оговорки

Контракты в `internal/` пока нестабильны и будут корректироваться до первого коннектора; релизный формат манифеста объявляется стабильным только после тестов реального восстановления. Отсутствие P0-функций в текущем коде не означает их исключения из требований.
