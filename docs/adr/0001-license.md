# ADR-0001 — GPL-3.0-only

**Статус:** принято, 2026-11-08.

## Решение

Исходный код BackupHub распространяется по **GNU GPL version 3 only** (SPDX `GPL-3.0-only`). Файл `LICENSE` содержит полный юридический текст.

## Обоснование

BackupHub — self-hosted система, устанавливаемая администратором на свою площадку. GPLv3 гарантирует доступность исходников при распространении модифицированного продукта. Вариант AGPLv3 специально распространяет обязанность предлагать исходный код также на взаимодействие с модифицированной программой по сети; для задач этого проекта такую дополнительную обязанность не считаем необходимой.

GPL и AGPL — разные условия при сетевом предоставлении сервиса; выбор сделан осознанно, без обещаний «обязательной публикации» приватных изменений у каждой организации, которая просто запускает BackupHub на своём сервере.

Зависимости проходят license compliance перед выпуском. Предпочитаемый Restic использует BSD-2-Clause, совместимую с GPLv3; требования его уведомлений при распространении соблюдаются отдельно. Лицензия BackupHub не меняет лицензию Restic.

## Последствия

Все новые файлы проекта следует писать с совместимыми лицензиями. Новые сторонние зависимости нельзя добавлять без проверки условий и корректного сохранения notices. Текст `GPL-3.0-only` должен быть согласован в GitHub и метаданных релизов.
